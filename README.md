# Zerodha Clone - Backend API

Backend service powering the Zerodha Clone trading platform. Built using Node.js, Express.js, and MongoDB, this API handles authentication, user management, holdings, positions, and order workflows.

## Features

### Authentication

* JWT-based authentication
* Secure cookie handling
* User registration and login and logout

### User Management

* User account creation
* Authentication middleware
* Protected routes

### Trading APIs

* Holdings Management
* Positions Management
* Orders Management
* Watchlist Data APIs

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT

## Database Schema

### Collections

* Users
* Holdings
* Positions
* Orders

## API Responsibilities

* User Authentication
* Holdings Retrieval
* Order Creation
* Position Tracking
* Portfolio Data Management

## Installation

```bash
git clone https://github.com/OptiSolvD/zerodha-clone-backend-.git
cd backend
npm install
npm start
```
